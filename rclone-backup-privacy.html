rclone-backup privacy policy

rclone-backup is the OAuth client that the rclone program uses to copy one person's files to that person's Google Drive. Its only user is the Google account that created it.

What it can access

Through the drive.file scope, it reaches only the Drive files that rclone created or opened through it.

What it collects

It collects nothing and has no server. rclone runs on the user's own computers and keeps its Google sign-in token there.

Who receives data

Only Google receives data. It stores the copied files in the user's Drive.

How long data is kept

The copied files stay in the user's Drive until the user deletes them. The sign-in token stays on the user's computers until the user deletes it or revokes access at myaccount.google.com/permissions.

Effective 2026-11-13.
